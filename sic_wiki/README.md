# Si/C Wiki：硅碳负极容量跳水

这是一个无需构建工具的静态图文页面，解释硅碳负极锂离子电池出现容量“膝点”和加速衰减的原因。

直接用浏览器打开 `index.html` 即可阅读。页面包含：

- 原创硅碳颗粒退化示意图
- 容量膝点曲线
- 机械、界面、传输网络和锂库存四条耦合失效链
- 用低倍率恢复、阻抗、厚度/压力等现象辅助归因的诊断表
- 设计缓解方向与论文链接

## 文件

- `index.html`：正文与无障碍语义结构
- `styles.css`：响应式页面样式及代码绘制的小型示意图
- `assets/si-carbon-degradation.png`：AI 生成的概念性科学插图（非实验图像、非按比例绘制）

## 内容边界

正文主要面向液态电解液锂离子全电池中的硅/石墨或硅碳复合负极。容量曲线与插图用于解释机制，不代表具体电芯或实验数据。对实际失效进行归因时，需要结合倍率恢复测试、阻抗、库仑效率、三电极电位以及拆解表征。
