Model assumptions模型假设

  • One scalar normalized concentration represents both lithium content and the crystalline/amorphous phase state.一个归一化浓度标量同时表示锂含量和晶态/非晶态相状态。 Evidence: Phase-Field Model and Boundary Conditions, p.5 (body text) | confidence: high
  • Chemical expansion is isotropic, elastic properties vary with concentration, and irreversible deformation follows volume-preserving isotropic J2 plasticity with linear hardening.化学膨胀各向同性，弹性性质随浓度变化，不可逆变形采用体积不变、线性硬化的各向同性 J2 塑性。 Evidence: Problem Description and Constitutive Model, p.3 (body text); Numerical Results, p.6 (table) | confidence: high
  • Mechanical relaxation is fast relative to diffusion, so quasi-static force balance holds at every transport time step; plastic free energy is assumed independent of concentration.力学松弛相对于扩散足够快，因此每个输运时间步都满足准静态平衡；塑性能被假设为与浓度无关。 Evidence: Problem Description and Constitutive Model, p.3 (body text); Phase-Field Model, p.5 (equation) | confidence: high

  • The simulated diffuse-interface width remains close to the 1.12 nm analytical value throughout lithiation.模拟弥散界面宽度在整个锂化过程中保持接近 1.12 nm 的解析值。 Evidence: Numerical Results, p.7 (equation); Numerical Results, p.8 (figure) | confidence: high
