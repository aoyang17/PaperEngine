# Argument Anatomy

Use this reference to identify the paper's argumentative structure before writing the report.

## Required Argument Map

- `gap`: what is missing or underexplored before this work.
- `core_contribution`: what the paper claims to add.
- `method_logic`: how the method, theory, system, or dataset addresses the gap.
- `decisive_evidence`: the evidence ladder that most directly supports the contribution.
- `limitations`: where the paper bounds its own claims or where evidence is weak.
- `future_work`: concrete next directions stated or strongly implied by the paper.

## Reading Cues

- Abstract often follows value -> gap -> contribution -> result -> significance.
- Introduction often contains explicit gap terms such as "however", "remains", "underexplored", or "lack".
- Results sections often start paragraphs with the conclusion, then give figure/table evidence.
- Figure/table captions may contain interpretation, not only description; cite captions when using visual evidence.
- Discussion/limitations bound the claim and should not be skipped.

For central claims, always separate `what_it_proves` from `what_it_does_not_prove`; this is the fastest way to avoid overclaiming.

Do not turn the argument map into generic praise. Each item must cite source refs.
